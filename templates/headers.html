Getting the headers

  1. Gmail: open the email, the three-dot menu, then "Show original". Copy everything above the message text.
  2. Outlook: open the email, then "View message source" (or File, Properties, Internet headers).
  3. Apple Mail: View, Message, All Headers.

Headers can contain your address, names and IP addresses. Nothing you paste is uploaded or sent anywhere; the page couldn't if it tried.

Did it pass?

Passing doesn't make an email safe: a scammer's own domain can pass all three. They show which domain really sent it, so check that it's the one you expect. Only the results your own mail server added count; the analyser reads the topmost ones, because lower ones can be written by the sender.
