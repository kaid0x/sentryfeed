What it looks at

  • Email: {{ ui.term("spf", "SPF") }}, {{ ui.term("dmarc", "DMARC") }}, {{ ui.term("dkim", "DKIM") }}, {{ ui.term("mta-sts", "MTA-STS") }} and {{ ui.term("tls-rpt", "TLS-RPT") }}, plus who handles the domain's email.
  • Website: whether http sends you to https, {{ ui.term("hsts", "HSTS") }}, the certificate, and {{ ui.term("security-txt", "security.txt") }}.
  • DNS: {{ ui.term("dnssec", "DNSSEC") }} and {{ ui.term("caa", "CAA") }}.

Only public settings: the DNS records every mail server reads, and what a browser sees when it opens the home page, plus two standard files (security.txt and the MTA-STS policy). It doesn't scan for weaknesses, try passwords or touch anything private, and it won't connect to private or internal addresses.

Results are kept for an hour, so a shared link shows the same report, then deleted. There's no public list of checked domains. To keep it fair, each visitor can run {{ per_hour }} new checks an hour.
