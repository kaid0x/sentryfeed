How it stays private

  1. Your browser turns the password into a SHA-1 hash, a 40-character fingerprint such as 5BAA61E4C9…
  2. Only the first 5 characters go to SentryFeed, which asks the breach database for every leaked hash starting with them, usually several hundred.
  3. Your browser compares that list with the rest of the hash itself. Neither SentryFeed nor the database sees the password or its full hash.
