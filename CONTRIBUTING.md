# Contributing to SentryFeed

Suggestions, bug reports and focused pull requests are welcome. This is Haseeb
Ashfaq's personal project; contributions do not make it an open-source release.
Read [the project terms](LICENSE) before using current original material.

## Before making a change

Open an issue for larger changes so we can agree on scope. Explain the problem,
expected behaviour and how to reproduce it. For a pull request, describe your
change, the checks you ran and any limitations. A contribution fork and local
testing are allowed for preparing a submission; deploying a replica is not
licensed by the current project terms. Earlier MIT material is an exception,
as explained in LICENSE.

Keep feed and submitted text untrusted, preserve the Content Security Policy,
and avoid external scripts or fonts. Keep changes small and accessible.
Never commit keys, tokens, databases, private reports, real hashes or passwords.
Do not post exploitable security details or secrets in a public issue; use
GitHub private vulnerability reporting if enabled, otherwise ask for a private
reporting channel without disclosing the vulnerability publicly.

original code or documentation for inclusion, you grant Haseeb Ashfaq a
non-exclusive, worldwide, perpetual, irrevocable, royalty-free licence to use,
copy, modify, distribute, sublicense and display your contribution as part of
SentryFeed, including in future versions under different terms. You retain
ownership of your contribution. This grant applies to original submitted work,
not third-party material you cannot license.

Disclose third-party material, its source and its licence before inclusion.
Ordinary suggestions and bug reports do not transfer ownership of your work.
All contributions are reviewed; submission does not guarantee acceptance.
